
이 저장소는 개인 포트폴리오 사이트입니다.  
- 사이트의 메인 페이지는 [ptf_2022](https://amykkkk.github.io/ptf_2022) 에서 확인할 수 있습니다.
- 각 폴더별 세부 내용은 해당 폴더의 파일을 참고하세요.


### ptf2021

- `ptf2021` 폴더는 여러 하위 `ptf` 폴더들로 구성되어 있습니다.
- 각 하위 `ptf` 폴더는 개별 프로젝트 또는 작업물을 포함하고 있으며, 각각의 프로젝트에 대한 소스와 리소스가 정리되어 있습니다.

### ptf2022

- `ptf2022` 폴더는 메인 프로젝트만 포함하고 있습니다.
- 주요 작업물과 결과물을 중심으로 정리되어 있습니다.
